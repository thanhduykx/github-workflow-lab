# GitHub Workflow Lab

Repo cá nhân để thực hành branch, commit, pull request và kiểm tra kết quả merge.
Các bài tập tập trung vào tài liệu và mẫu đóng góp có thể dùng lại.

## Bắt đầu

Đọc [hướng dẫn pull request](docs/pull-request-workflow.md), sau đó chọn một thay đổi nhỏ có kết quả kiểm tra rõ ràng.

## Tài nguyên

- [Mẫu báo lỗi](.github/ISSUE_TEMPLATE/bug_report.md): ghi bước tái hiện, môi trường và bằng chứng.
- [Mẫu pull request](.github/pull_request_template.md): mô tả thay đổi, kiểm tra và ảnh hưởng.

GitHub tự đề xuất mẫu báo lỗi khi mở issue và điền mẫu mô tả khi mở PR mới.
Chỉ điền những kết quả đã xác minh; che thông tin riêng tư trong mọi log và ảnh.

## Phạm vi

Repo này là môi trường luyện tập, không phải dịch vụ đang vận hành.
Không lưu mã nguồn dự án khác, thông tin đăng nhập hoặc dữ liệu người dùng.

GitHub tự quyết định cấp Achievements. Xác minh huy hiệu tại [hồ sơ thanhduykx](https://github.com/thanhduykx?tab=achievements).
